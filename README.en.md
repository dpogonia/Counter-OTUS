# Counter

A tap counter for iPhone and iPad. An OTUS study project: one screen built with UIKit and a storyboard.

## What it does

The screen shows a number, plus and minus buttons, and a reset. The counter does not go below zero. Each change is written into a history with the time.

The value is stored in `UserDefaults` and read on the next launch.

## Stack

UIKit, Storyboard, UserDefaults.

## Run

```bash
git clone https://github.com/dpogonia/Counter-OTUS.git
cd Counter-OTUS
open Counter.xcodeproj
```

Run the **Counter** scheme on an iPhone simulator.
