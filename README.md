# Counter

Счётчик нажатий для iPhone и iPad. Учебный проект OTUS: один экран на UIKit и Storyboard.

## Что умеет приложение

На экране число, кнопки «+» и «−» и сброс. Ниже нуля счётчик не уходит. Каждое изменение пишется в историю со временем.

Значение хранится в `UserDefaults` и читается при следующем запуске.

## Стек

UIKit, Storyboard, UserDefaults.

## Запуск

```bash
git clone https://github.com/dpogonia/Counter-OTUS.git
cd Counter-OTUS
open Counter.xcodeproj
```

Запустите схему **Counter** на симуляторе iPhone.
